# 画像スプライト 資料（2026-11-12 更新：32コマ版）

`assets/sprites/<char>.webp` は各キャラのモーションシート。
12288×384px、左から32コマ（各384×384、透過WebP）。全キャラ合計 約11MB（キャラごとに遅延読み込み。同時に読み込まれるのは巫女＋現在のボスだけ）。

## コマ構成

基本ポーズ i（0〜7）ごとに [A, C, B, D] の4コマが並ぶ（A=基本、B=中間、C=AとBの間、D=Bの次）。
combined index = 4i + (A:0, C:1, B:2, D:3)。

## 浮遊表現（ボス共通）
- 移動コマ8〜15は空中浮遊サイクル：脚を揃えて垂らし、上下に漂う8コマをこの順でループする（歩行サイクルではない）。ボスは全員浮いているため、地面を歩く脚運びにはしない。
- 浮遊感はシート単体ではなく、コード側のボブと傾きと合わせて出す。ボブは描画位置だけに加える sin 波の上下動（振幅およそ5px、周期およそ1.6秒、ボスごとに位相をずらす）で、待機・移動の両方で常に漂う。傾きは横移動の速さに応じてスプライト全体を体の中心を軸に最大およそ4度、進行方向へ前傾させる（攻撃ポーズ固定中・被弾中・撃破演出中は傾けない）。
- ボブも傾きも見た目だけの加工で、当たり判定や移動ロジックの座標は変えない。移動サイクルの速度連動とクロスフェードは従来どおり維持する。

## アニメーション指針
- 待機は12fps、移動・走りは実移動速度に連動（巫女は通常走行で約21fps、ボスは実測速度×0.085で12〜30fps）でサイクルを回す。循環サイクルは次コマを位相の端数ぶん薄く重ねるクロスフェードでコマ間を補間し、コマ送りの段差（もっさり感）を消す。
- ボス／巫女が実際に移動している間は必ず移動（走り）サイクルを使う。待機サイクルのまま滑らせない。移動サイクルの位相は累積式で進めるので、速度が変わってもコマが飛ばない。
- ボスの移動速度（ローム／追跡）は3倍拡大に合わせて引き上げる（従来の約1.5倍を目安）。攻撃間隔・弾幕・HPは不変。
- 攻撃はテレグラフ中に構え 16→19、発動で解放 20→23 を順に再生。
- 被弾は 24→27、撃破は 28→31 を順に再生。
- 被弾の白フラッシュ：全身が真っ白になる演出は強攻撃・パリィ反射のヒット時だけ。弱攻撃のヒットでは短い明滅（0.04秒程度）のみにして、頻繁にチカチカさせない。

## ボスの大きさ（重要）
- 戦闘中のボスの見た目の大きさは、現在の約3倍にする（＝巫女の本体高さの約3倍、約207px相当）。
- 基準：ボスのコマ0で「女の子本体の頭頂から足元までの実寸高さ」が、巫女コマ0の本体高さの約3倍になるスケール。浮遊物（がしゃどくろの頭蓋骨など付随物）や九尾の尾は高さの基準に含めない。
- ボスへの攻撃の当たり判定（本体に当たる範囲）も、見た目に合わせて同じ比率（現在比3倍）で拡大する。プレイヤー側の被弾判定（白いボール）は変更しない。
- 足元のアンカー（接地位置）は維持する。大きくなった分、画面上端や移動範囲で極端なはみ出しが出ないよう、出現・移動の縦位置は必要なら調整する。
- カットイン・図鑑・ボスセレクトの立ち絵サイズは従来のまま（カットインは画面内に収める上限を維持）。

## 向き
- ボスの絵は左向き。ボスがプレイヤーより左にいる場合は左右反転してプレイヤーの方を向かせる。
- 巫女の絵は右向きに反転済み。プレイヤーの向き（facing）に合わせて反転する。

## 第弐形態シート（_f2）

`assets/sprites/<char>_f2.webp` は各ボスの第弐形態（第2形態）専用シート。
6144×384px、左から16コマ（各384×384、透過WebP）。対象はボス7人（tengu / gashadokuro / yukionna / fujin / raijin / kyubi / nurarihyon）。巫女には無い。

### コマ対応（16コマ版は第1形態の32コマ版と割り当てが異なる）

- 待機サイクル: 0–3（4コマ）
- 浮遊サイクル: 4–7（4コマ）
- 構え（攻撃ポーズ固定）: 8
- 解放（攻撃ポーズ固定）: 10
- 被弾: 12–13
- 撃破: 14–15

待機・浮遊は4コマしかないため、コード側は位相（animPh）を半分に割って周期の長さを第1形態（8コマで約1.6秒）とそろえる。攻撃中は第1形態と同じくポーズ固定（構え=8／解放=10、補間なし）。

### 変身ルール

- 各ボスはHPが半分以下になった瞬間に一度だけ変身する（風神・雷神は各自のHPで個別に変身）。
- 変身演出は約1.0秒。その間ボスは無敵・攻撃停止し、場の敵弾は全て消去され、上部帯に「第弐形態 ― （ボス名）」のバナーが出る。
- 演出後にシートを _f2 へ切り替える。表示サイズ・足元アンカー（IMG_CELL 共用）・当たり判定は第1形態と同一。
- _f2 は戦闘開始時（startBoss→preloadBossImg）に裏で先読みする。読み込めていない間は第1形態シートのまま表示し、読み込み完了後に切り替わる。
- 画像が読み込めない場合のコード描画フォールバックでは、変身時にボスごとのモチーフ・オーラ（ハード以上のオーラ意匠）を難易度に関わらずまとうことで代用する。
- ボスHPバーには50%位置に目印（変身ライン）が付く。
- 第弐形態では専用攻撃がローテーションに加わる（目安：攻撃ターンの約3回に1回）。天狗「大羽根嵐」、がしゃどくろ「髑髏の大口」、雪女「絶対零度」（結晶34個＋氷柱3連鎖＋氷の欠片の雨）、風神雷神「風雷双渦」（どちらか一方が第弐形態なら使用可）、九尾は炎斬りが「連斬」化（9→14回）＋狐火乱舞の増量、ぬらりひょんは結界崩壊後に一度だけ5秒で全回復＋分身+1。

## 統合ルール
- 画像が読み込めていない／読み込み失敗のキャラは、今までのコード描画にフォールバックする。
- 移動速度・攻撃間隔・HPなどのゲームバランスは変えない。変えるのは絵とアニメーション、ボスの表示サイズと本体当たり判定の追随のみ。
- アンカー: セルの下端中央を、現在のスプライトと同じ接地位置に合わせる。
- 九尾の「尾が光る」予告は、光る尾の色の光をスプライト背面（尾側）に重ねて描き、既存のバナー表示と併せて視認性を維持する。
- 巫女の衣装スキンは画像では緋（デフォルト）の見た目固定。当たり判定ボールの色は従来通りスキン連動。
- 雑魚敵は画像なし（従来のコード描画のまま）。
